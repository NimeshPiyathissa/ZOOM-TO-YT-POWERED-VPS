# Zoom to YouTube Live Streaming v1.0.1

A maintenance release: the continuous-integration checks now pass on GitHub (Ubuntu 24.04), and the repository has
its final name. Nothing changes for a running installation - the fixes are in the tests and in shell-script style.

## Changes

- **Repository renamed** to `NimeshPiyathissa/ZOOM-TO-YT-POWERED-VPS`. The installer, README, docs and issue
  templates use the new URL. GitHub redirects the old name, so the v1.0.0 install command keeps working.
- **CI fixes:** five shell lines rewritten from `A && B || true` to explicit `if` statements (shellcheck SC2015 on
  the shellcheck version GitHub uses). Same behaviour.
- **Test fixes** (the test suite now passes on Linux CI as well as on an installed server and on Windows):
  - tests that need the `zoombot` / `dashboard` accounts get stand-ins when those accounts do not exist;
  - Zoom-layout tests build their test pictures in RGB, so older ffmpeg (6.1) no longer shortens them by a row;
  - a capture-framing test no longer asks a real X display for its size.

## Upgrading

```bash
sudo /opt/zoom-stream/update.sh
```

A fresh install uses the same one command as before:

```bash
curl -fsSL https://raw.githubusercontent.com/NimeshPiyathissa/ZOOM-TO-YT-POWERED-VPS/main/install.sh -o install.sh
sudo bash install.sh
```

## Known issues

Unchanged from [v1.0.0](v1.0.0.md#known-issues-and-limitations). In addition: during the v1.0.0 release testing,
`uninstall.sh` once exited with status 1 after printing "Uninstall complete" (everything had been removed). It did
not happen again in three traced runs and no cause was found in the code, so it is not changed in this release.
