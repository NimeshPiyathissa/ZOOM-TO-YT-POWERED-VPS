# Zoom to YouTube Live Streaming v1.0.3

A bug-fix release for one fault that affects **every install made with v1.0.0, v1.0.1 or v1.0.2**.

## Fix

- **The Remote GUI could not connect** ("VNC authentication failed - the stored VNC password was rejected"). The
  password was never wrong. The installer had made the folder `/etc/zoom-stream` readable by root only, but the
  dashboard keeps the key to its encrypted secret store in that folder. Without the key the secret store stayed
  locked, so the dashboard had no VNC password to give to the remote screen. The same fault affected the interactive
  preview on the Control panel and the sign-in view on the Accounts page, which use the same connection.

  Updating repairs it. If you cannot update right now, this does the same:

  ```bash
  sudo chmod 755 /etc/zoom-stream && sudo systemctl restart dashboard
  ```

  The installer's own files in `/etc/zoom-stream/installer` stay private, and the key file itself is still readable
  only by root and the dashboard service.

## Added

- **A real self-check.** The installer, `update.sh` and `doctor.sh` now check, as the dashboard's own user, that the
  secret store unlocks and that the remote-screen password really logs in. Before, they only checked that pages
  loaded, which is why this fault was not caught. You can run it yourself:

  ```bash
  cd /home/dashboard/app && sudo -u dashboard /home/dashboard/venv/bin/python -m app.cli selfcheck
  ```

## Upgrading

```bash
sudo /opt/zoom-stream/update.sh
```

`update.sh` refuses to run during a broadcast, takes a backup first and rolls back automatically if anything fails.
Running streams, Zoom and Chrome are not restarted; only the dashboard is.
